# Decision 191 — M25.5 Interface Adapter Boundary

## Status
IMPLEMENTED / VERIFIED LOCALLY

## Purpose
M25.5 defines the boundary between an external interface representation and JARVIS's canonical M25.1 backend contract.

The adapter translates an external envelope into an immutable `InterfaceRequest`, delegates only to the injected interface backend, and translates the canonical `InterfaceResponse` back into an immutable external representation. It is a translation boundary, not an authority or semantic boundary.

## Scope

```text
External GUI / CLI / API / Voice Envelope
                ↓
        InterfaceAdapter       ← M25.5
                ↓
        InterfaceRequest
                ↓
       Interface Backend
                ↓
        InterfaceResponse
                ↓
External Interface Representation
```

## Boundary rules

- External input must be a mapping and must contain the six canonical request fields.
- String operation values are translated to the existing `InterfaceOperation` enum; unknown values are rejected.
- Canonical `InterfaceRequest` construction remains responsible for identity, typing, immutability, payload, and metadata validation.
- The adapter does not select M24 stages, interpret lifecycle semantics, or dynamically dispatch operations.
- The adapter delegates only through the injected backend `handle` seam.
- Returned responses must be the exact canonical `InterfaceResponse` type.
- Enum values are translated back to their stable string values for external consumers.
- Returned payload and metadata are recursively frozen; the external envelope is immutable after crossing the boundary.
- Caller-owned request mappings are never mutated.
- Backend-owned response identity, operation, status, payload, and metadata are preserved.
- Adapter failures remain boundary failures; the adapter does not manufacture lifecycle artifacts.

## Explicit non-powers

```text
Interface Adapter ≠ Authority
Interface Adapter ≠ Orchestration
Interface Adapter ≠ Executor
Interface Adapter ≠ Persistence
Interface Adapter ≠ M24 Semantic Boundary
Interface Adapter ≠ AI Provider
Interface Adapter ≠ Truth / Certainty
```

## Design consequence

M25.5 gives GUI, CLI, HTTP, local API, and voice surfaces one canonical translation boundary. Interfaces can speak their own transport representation while JARVIS retains one internal request/response contract.

No interface may bypass the backend contract to reach M24 internals directly.
