# M35.1 — Authorized Execution Handoff

## Decision
Establish an immutable handoff contract that pairs an M34 bounded worker dispatch with an already-READY M7.10 `ExecutionPreparation`.

## Boundary
The handoff layer may only consume an existing READY preparation. It does not create authorization, validate policy, construct execution semantics, select providers, invoke tools, or execute work.

## Invariants
- dispatch identity is preserved
- the preparation must be READY and contain an execution request
- the execution request must match the dispatched step title
- handoff context explicitly records that authorization was not created here
- handoff context explicitly records that execution was not performed here

## Authority
M7 authorization, authorization-integrity validation, M7.10 execution preparation, M8 execution runtime, and M8.5 controlled agency remain authoritative.
