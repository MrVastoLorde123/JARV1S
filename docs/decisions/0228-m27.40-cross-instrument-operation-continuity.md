# M27.40 — Cross-Instrument Operation Continuity

## Decision

CHAT, CONTROL, MIND and CAPABILITIES should reveal the same ongoing operation rather than presenting independent page sessions.

A shared operation continuity layer carries the current mission, workspace, model, transition and runtime state while the operator changes instruments.

## Continuity contract

- The active operation remains visible when moving between instruments.
- Workspace and model context travel with the operation instead of being rediscovered on each surface.
- The current transition remains attached to the same work object.
- The hand-off records the previous instrument and current instrument so navigation reads as a causal transition.
- Runtime attention and guard state remain attached to the operation.

## Boundaries

The continuity layer is derived from `JarvisSnapshot` and browser session state only for navigation history. It does not create authority, mutate selected project state, execute actions, or expose private reasoning.

## Principle

**Change instruments, not operations.**
