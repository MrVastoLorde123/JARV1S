# M52.1 — Authorization Decision Boundary

Authorization remains distinct from confirmation.

A `GRANTED` authorization decision is an authority result for one explicitly `CONFIRMED` request. It does not itself select a provider or tool, request execution, or perform execution.

`DENIED` and `BLOCKED` decisions preserve the same downstream execution boundary.

The decision is immutable and must retain exact lineage to the confirmation result and confirmation request that it authorizes.
