# M46.1 — Initiative Candidate Boundary Decision

The initiative layer consumes M45 reasoning outputs and represents possible objectives worth downstream evaluation.

An `InitiativeCandidate` is not an instruction. It does not establish that an objective reflects user intent, truth, authorization, permission, scheduling, or execution readiness.

The candidate set preserves the exact reasoning identity and carries unresolved uncertainty forward. Downstream evaluation is responsible for deciding whether a candidate has sufficient value, evidence, and fit for further proposal handling.

This boundary intentionally stops before value assessment, scheduling, notification, authorization, or execution.
