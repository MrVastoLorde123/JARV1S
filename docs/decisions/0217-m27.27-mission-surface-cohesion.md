# M27.27 — Mission Surface Cohesion

## Decision
Mission Control should read as a single live operating surface rather than a collection of independent cards.

## Spatial model
The surface presents context and goal first, then model posture, project scope, pipeline progression, trace evidence and inspector details. Responsive rules preserve readable minimum widths before collapsing the composition.

## Live-state relationship
The mission surface remains presentation of the existing JARVIS snapshot. Visual emphasis may reflect active state, but styling must not invent execution, cognition, authorization or verification outcomes.

## Scrolling
Dense pipeline and trace regions may scroll internally when necessary so the overall mission surface remains stable.

## Boundary
This refinement changes presentation and responsive behavior only. It does not modify canonical runtime state, authority, execution, model routing or learning semantics.
