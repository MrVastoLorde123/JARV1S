# M27.43 — Interface Navigation and Surface Coherence

## Decision
The React `App` is the single authority for UI destination state. Auxiliary DOM-mounted navigation and cross-instrument presentation controllers are not installed globally.

## Rationale
The navigation state already exists in one React state value (`space`). M27.33–M27.42 introduced additional DOM observers that inferred destination state from rendered button text and mounted extra surfaces into pages. This created synchronization drift, especially after the visible `WORK → PROJECTS` language transformation, and caused CHAT to accumulate multiple unrelated overlays.

## Contract
- App navigation state determines the active destination.
- Page components own their destination content.
- Mission Spine remains an intentional global orchestration layer.
- SELF runtime remains an intentional runtime observation layer.
- Space continuity, operational instrument, operation continuity, and causal-thread controllers are not globally installed.
- Historical M27.33–M27.42 source files remain preserved for reference and later reintegration through the React state model.
- No presentation layer may infer application identity from mutable DOM labels.
- No cleanup may change backend authority or execution semantics.

## Expected result
Navigation becomes deterministic and shared across destinations, while CHAT returns to a single conversation/workspace/research/planning surface instead of being composited from multiple independent DOM-mounted systems.
