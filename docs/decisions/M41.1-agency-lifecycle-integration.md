# M41.1 — Agency Lifecycle Integration Boundary

## Decision

M41 introduces a single immutable integration record over the existing V6 agency lifecycle contracts from planning through execution observation, independent verification, recovery, and operational reconciliation.

The integration record joins already-authoritative identities for inspection. It does not replace any underlying authority boundary or create a new decision surface.

## Boundaries

- Work State remains the operational-state authority.
- Work Planning remains proposal-only.
- Task Orchestration remains coordination-only.
- Dispatch and Execution Handoff remain bounded handoff contracts.
- Controlled Agency remains the execution authority/runtime.
- Execution Outcome remains observation only.
- Verification remains external and independent.
- Recovery remains a bounded continuation/stop decision.
- Recovery Reconciliation remains operational projection only.
- M41 does not authorize, execute, verify, invoke tools, select providers, create credentials, or persist state.
- Cross-stage identity mismatches fail closed.
- `authorization_granted` and `execution_requested` remain explicit false values on the integration read model.

## Rationale

M40 provided a lifecycle read model but stopped before execution and verification. M41 completes observability across the full V6 chain without introducing a second lifecycle authority. Consumers can inspect one coherent record instead of reconstructing identity relationships independently.
