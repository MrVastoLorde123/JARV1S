# M27.1 — Interaction

## Decision
JARVIS gains an explicit human interaction contract over the existing command surface. Interaction is a request/response lifecycle, not an implicit execution trigger.

## Contract
- User input is explicit and bounded by the existing `/api/command` transport.
- Interaction state distinguishes composing, submitting, processing, response, and failure.
- Requests carry session identity, request identity, content, and submission time.
- Responses remain observations of the command transport; a response is not itself authority evidence.
- Automatic execution is explicitly false at the interaction layer.
- Invalid or empty interaction payloads normalize to safe representations rather than becoming UI truth.
- The interaction contract remains presentation/transport-level and does not create a second authority system.

## Acceptance
`verify_m27_interaction.py` confirms the existing UI exposes an explicit command submission path and the typed M27 interaction contract. UI build and the established regression suite remain the final milestone gates.
