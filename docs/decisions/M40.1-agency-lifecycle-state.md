# M40.1 — Agency Lifecycle State Boundary

## Decision

M40 introduces an immutable aggregate read model over the existing V6 agency contracts: Work State, Work Plan, Task Orchestration, and optional Recovery Reconciliation.

The aggregate joins identities for inspection and lifecycle visibility. It does not replace the authority of any underlying contract.

## Boundaries

- Work State remains the operational-state authority.
- Work Planning remains proposal-only.
- Task Orchestration remains coordination-only.
- Recovery Reconciliation remains a projection of an existing recovery decision.
- M40 does not authorize, execute, verify, invoke tools, select providers, or create credentials.
- Aggregate identity mismatches fail closed.
- `authorization_granted` and `execution_requested` are explicit false values.

## Rationale

V6 now has a complete chain from work substrate through execution, independent verification, recovery, and operational reconciliation. A single immutable read model prevents consumers from reconstructing that chain inconsistently while preserving the separate authority boundaries.
