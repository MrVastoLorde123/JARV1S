# M38.1 — Verification to Recovery Boundary

## Decision

M38 introduces a bounded recovery decision layer between independent verification outcomes and objective continuation.

A verified result closes the current objective. A rejected result may produce a bounded continuation proposal through the existing `DriveabilityController`. Blocked and uncertain verification stop without creating execution authority.

## Boundaries

- Verification remains external to this module.
- Recovery is a decision/proposal layer, not an execution layer.
- Recovery never grants authorization or requests execution.
- Existing M7/M8 authority and M9.7 driveability remain authoritative.
- Observation, verification, recovery proposal, authorization, execution, and evidence remain distinct identities.
