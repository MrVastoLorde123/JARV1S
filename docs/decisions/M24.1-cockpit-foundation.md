# M24.1 — Cockpit Foundation

## Decision
JARVIS gains a standalone visual cockpit surface before backend integration. The cockpit exposes operational state, active work, activity, health, and authority boundaries without pretending that UI state is execution authority.

## Contract
- The cockpit is a presentation surface, not a second control plane.
- The initial demo is inert and invokes no capabilities.
- Operational lifecycle labels are visible without exposing private chain-of-thought.
- Authority boundaries remain explicit in the UI.
- Backend integration is deferred to the following M24/M25 boundaries.
- The surface must remain useful on desktop and narrow screens.

## Acceptance
The M24.1 focused test proves the required files and operational markers exist and that the demo contains no network/tool invocation surface.
