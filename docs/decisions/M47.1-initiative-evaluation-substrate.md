# M47.1 — Initiative Evaluation Boundary

M47 establishes a descriptive evaluation layer between initiative candidates and later prioritization/proactive proposal logic.

Evaluation may record bounded value, feasibility, urgency, rationale, and uncertainty. Those values are evidence for downstream reasoning; they are not authorization, scheduling permission, execution intent, or a selected winner.

Uncertainty is carried forward unchanged from the candidate set. Identity is fail-closed: evaluations must belong to the exact candidate set they describe.
