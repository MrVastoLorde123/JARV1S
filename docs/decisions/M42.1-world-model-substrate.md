# M42.1 — World Model Substrate Boundary

## Decision

M42 introduces an immutable, provider-neutral world-model substrate over existing `WorldObservation` data.

The model represents bounded current-context facts and preserves observation lineage. It does not convert observations into authoritative truth, permissions, intent, authorization, or execution authority.

## Boundaries

- Existing perception/world observations remain upstream evidence.
- World-model facts preserve source observation identity.
- `OBSERVED` status describes provenance, not truth.
- Conflicting or incomplete upstream evidence is not silently resolved here.
- M42 does not authorize, execute, invoke tools, mutate memory, or select providers.
- Truth establishment remains outside the substrate.

## Rationale

The cognitive architecture requires a distinct World Model / Current Context layer between perception/evidence and reasoning. M42 establishes that boundary without prematurely implementing reasoning or truth arbitration.
