# M43.1 — World Model Qualification Boundary

## Decision

M43 introduces deterministic freshness and conflict qualification for existing M42 world-model facts.

A fact is `USABLE` only when its observation time is current within the configured age bound and no peer fact for the same subject/domain disagrees. Stale, future, invalid, and conflicting facts remain explicit classifications rather than being silently promoted or discarded.

## Boundaries

- M42 remains the world-model substrate authority for representation only.
- M43 assesses freshness and conflict; it does not select truth.
- Conflicts are preserved with peer identities rather than resolved.
- Qualification does not mutate the source snapshot.
- M43 does not infer user intent, authorize, execute, mutate memory, or select providers.
- `truth_established` and `authority_granted` remain false.

## Rationale

A current-context model needs to distinguish usable observations from stale, malformed, or contradictory state before downstream reasoning consumes them. That qualification belongs after representation and before reasoning, while truth arbitration remains a later and separate boundary.
