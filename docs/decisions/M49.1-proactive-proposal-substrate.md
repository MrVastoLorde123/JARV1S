# M49.1 — Proactive Proposal Substrate

## Decision
Introduce an immutable proposal boundary downstream of initiative evaluation and information-gain assessment.

## Boundary
A proactive proposal is a descriptive/advisory candidate for downstream consideration. It does not establish truth, infer user intent as fact, request scheduling or notification, request authorization, execute capabilities, select providers/tools, or mutate memory/world state.

## Lineage
Every proposal set is bound to one initiative evaluation set and one information-gain assessment with the same evaluation-set identity. Candidate, opportunity, and uncertainty references must belong to those supplied inputs.
