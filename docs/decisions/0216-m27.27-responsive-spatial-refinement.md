# M27.27 — Responsive Spatial Refinement

## Decision
The interface should preserve semantic readability before collapsing content into narrow vertical columns. Responsive behavior must adapt the spatial system, not merely shrink individual cards.

## Mission Flow
Mission Flow remains a live presentation of shared snapshot state. Its project rail, pipeline and inspector should retain clear spatial relationships as viewport width changes.

## SELF
SELF activity is a horizontal-first internal observation rail on desktop. Compact widths may collapse it, but the default desktop presentation should expose concurrent self-observation without a tall log-like stack.

## Containment
Cards, text and controls should not create narrow columns when usable horizontal space remains. Minimum content widths are preferred over premature two-column compression.

## Boundary
This refinement remains presentation-only. It does not change canonical runtime state, authority, execution, learning, or model behavior.
