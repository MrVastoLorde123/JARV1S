# M36.1 — Agency Execution Bridge

## Decision

M36 adds one bounded bridge between the M35 authorized execution handoff and the existing M8.5 `ControlledAgency` runtime.

The bridge consumes the exact `ExecutionPreparation` already proven READY by M7.10 and carried by M35. It delegates that preparation to `ControlledAgency.run()` without creating a new execution path.

## Boundary

M36 does not:

- create authorization;
- evaluate policy;
- prepare execution;
- select providers or capabilities;
- invoke tools directly; or
- bypass the existing M8.5 runtime.

`ControlledAgency` remains responsible for bounded execution, lifecycle observation, step limits, and provider handoff through the existing M8/M7 architecture.

## Result

The bridge returns immutable linkage between the M35 handoff and the M8.5 result so downstream agency state can retain execution identity, assignment identity, observations, and stop reason without manufacturing authority.
