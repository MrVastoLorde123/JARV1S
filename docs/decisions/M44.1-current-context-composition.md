# M44.1 — Current Context Composition Boundary

## Decision

M44 introduces a bounded current-context composition layer between qualified world-model facts and downstream reasoning.

Only M43 `USABLE` facts are admitted. Stale, invalid, and conflicting facts remain explicitly excluded rather than silently resolved.

## Boundaries

- M42 remains authoritative for world-model representation.
- M43 remains authoritative for freshness/conflict qualification.
- M44 is composition only; it does not establish truth.
- Current context does not infer user intent, grant permission, authorize actions, or execute capabilities.
- Snapshot/qualification identity must match exactly.
- Context admission is not truth arbitration.

## Rationale

The cognitive architecture needs a stable, bounded object that downstream reasoning can consume without independently reconstructing freshness and conflict rules. M44 provides that object while preserving explicit uncertainty and exclusion.
