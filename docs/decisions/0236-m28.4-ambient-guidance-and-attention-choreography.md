# M28.4 — Ambient Guidance and Attention Choreography

## Decision
The living-world interface may actively guide the operator's attention, but it must do so through the environment rather than reverting to application-style navigation or persistent notification panels.

## Interaction model
JARVIS can implicitly communicate:

- **Working** — move attention toward the active mission region.
- **Thinking / Learning** — make the context field become the visually important region.
- **Monitoring** — bring runtime conditions forward through pulse and saliency.
- **Needs You** — create a localized decision signal.
- **Offline** — reduce environmental certainty instead of pretending normal operation continues.
- **Waiting** — remain quiet and present.

The operator remains free to inspect any region directly. Guidance is an invitation, not navigation authority.

## Visual language
Different semantic objects use different physical signatures instead of relying on a color-coded legend:

- Missions behave like destinations / points of work.
- Context behaves like a surrounding field.
- Runtime behaves like a pulse / heartbeat.
- Abilities behave like instruments / active mechanisms.
- Attention behaves like a localized disturbance.

## Research-derived principles
This experiment borrows from several established interaction ideas: environmental framing and saliency for directing attention in open spaces; spatial/diegetic UI for keeping interaction inside the represented world; focus+context visualization for preserving overview while emphasizing the current region; and calm/ambient information systems for moving information between peripheral awareness and focused attention. The implementation is JARVIS-specific and does not attempt to reproduce any cited product or interface.

## Boundary
The guidance layer is presentation-only. Backend state remains authoritative. Guidance cannot invoke work, grant authority, mutate permissions, or decide user intent.

## Reversal condition
If guidance begins to feel like forced onboarding, quest markers, notification spam, or a dashboard overlay, reduce or remove the ambient layer and retain only the environmental state changes.
