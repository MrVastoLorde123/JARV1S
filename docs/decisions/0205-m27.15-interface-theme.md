# Decision 0205 — M27.15 Interface Theme and Contrast System

**Status:** IMPLEMENTED ON `feature/m27.15-interface-theme`

## Intent

Make the JARVIS interface readable and usable across dark and light environments without weakening the visual identity established in M27.14.

## Changes

- Restored the renderer baseline by creating the M27.15 branch directly from verified M27.14 commit `c80e81821a901290e8e214094ff48dc43ff5375e`.
- Added a readable dark glass token layer with materially brighter informational text and stronger heading contrast.
- Added a designed light mode rather than a mechanical color inversion.
- Added a persistent global theme control available across all interface spaces.
- Added `Ctrl/Cmd+Shift+L` as a theme toggle shortcut.
- Persisted the selected theme in browser local storage so the operator's choice survives reloads.
- Kept theme control outside the React shell so it remains available regardless of active JARVIS space.

## Visual invariant

Dark mode is the primary JARVIS command environment: near-black glass, restrained blue accents and high legibility. Light mode keeps the same spatial hierarchy and command-environment feel using cool neutral surfaces, dark typography and restrained blue accents.

## Authority invariant

Theme state is presentation-only. It does not affect JARVIS authority, orchestration, policy, authorization, execution or learning state.
