# M31.1 — Work State as the Agency Substrate

## Decision

JARVIS uses explicit **Work State** as the shared operational substrate for agency orchestration. A work state describes the current objective, lifecycle stage, blockers, evidence position, assigned agents, required capabilities, and the operational role currently appropriate for the work.

The role is dynamic and descriptive. It is not a permanent agent and does not carry authority.

## Contract

- Work State is distinct from Memory: it describes current work, not durable personal knowledge.
- Work State is distinct from Evidence: evidence supports claims; work state describes the active operational situation.
- Work State is distinct from Authority: state, role, capability, confidence, and planning do not grant permission.
- Role inference is deterministic and based only on observable work-state signals.
- Terminal work states cannot be interpreted as permission to execute new actions.
- Existing M7/M8 authority and execution boundaries remain authoritative.

## Dynamic role model

```text
requirements gap  -> REQUIREMENTS_ANALYST
unknowns/evidence -> RESEARCHER
planning/implementation -> TECHNICAL_LEAD
proposal review -> REVIEWER
verification failure -> DEBUGGER
verified completion -> RELEASE_COORDINATOR
otherwise -> GENERAL
```

The role can therefore change as Work State changes without creating a permanent collection of specialized agents.
