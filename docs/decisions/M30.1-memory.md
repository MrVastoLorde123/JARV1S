# M30.1 — Memory

## Decision
JARVIS receives a typed durable-memory contract over the existing structured-memory and evidence stores. Memory is persistent knowledge, not authority and not proof of truth by itself.

## Contract
- Memory records have stable identity, category, confidence, importance, and lifecycle status.
- Memory evidence is referenced explicitly with source identity and bounded confidence.
- Retrieval is read-only and preserves the requested status filter.
- Existing `src/memory/memory_store.py` and `src/memory/evidence_store.py` remain the persistence authorities.
- Memory does not expose authorization, execution, or permission fields as implied authority.

## Acceptance
The M30 focused contract tests validate bounded identity, evidence lineage, retrieval shape, and the absence of authority semantics. The repository verification script checks the contract against the existing memory architecture.
