# M32.1 — Work Planning

## Decision
JARVIS gains an explicit planning contract over the verified Work State substrate. Planning converts observable work state into an ordered, bounded proposal; it does not become authority or execution.

## Contract
- Every plan is anchored to one immutable `WorkState`.
- Plan steps have explicit identity, role, kind, capabilities, and dependencies.
- Dependency resolution is deterministic and read-only.
- Plans are bounded to a finite number of steps.
- Planning never authorizes, invokes, executes, or verifies a tool.
- Existing M7/M8 authority and execution boundaries remain authoritative.

## Consequence
Dynamic roles become operational inputs to planning without becoming permanent agents. JARVIS can determine what kind of work is needed before selecting a bounded execution path.
