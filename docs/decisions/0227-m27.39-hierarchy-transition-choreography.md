# M27.39 — Hierarchy Transition Choreography

## Decision

State-driven spatial hierarchy must transition as an intentional machine response rather than a visually abrupt DOM/layout change.

## Behavior

- Instrument surfaces animate hierarchy-relevant spacing and transforms when runtime state changes.
- Attention and model-gap states give the state boundary a controlled arrival motion.
- Waiting states settle the next-best-move region so the operator sees the held transition without visual noise.
- Expanded, focused, deferred and compact density states retain continuity while changing information weight.
- Motion remains restrained and communicates state transition; it does not simulate cognition.

## Boundaries

The choreography is presentation-only. Backend state remains authoritative; CSS transitions do not infer state, create actions, grant authority, or imply hidden reasoning.

## Principle

**A state change should feel like the machine responding, not like a page reloading.**
