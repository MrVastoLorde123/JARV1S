# M58.1 — Authorized Execution Recovery Bridge

## Decision

Bind the exact M57 authorized execution verification to the existing M38
bounded recovery decision boundary.

## Contract

M58 consumes one `AuthorizedExecutionVerification`, one user-established
`Objective`, and one matching `ContinuationCycle`, then delegates recovery to
`derive_recovery_decision`.

M58 does not:

- create or grant authorization;
- request or perform execution;
- select providers or tools;
- perform verification;
- create a new recovery policy.

The resulting recovery decision must retain the exact execution identity from
M57 and the exact supplied objective/cycle lineage.

## Authority boundary

M38 remains responsible for translating an independent `VerificationDecision`
into a bounded continuation/stop decision. M58 only binds that result back to
the authorized execution lineage.
