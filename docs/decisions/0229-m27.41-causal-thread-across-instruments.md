# M27.41 — Causal Thread Across Instruments

## Decision

Cross-instrument continuity is now expressed as a causal thread layered above the operational instrument surface.

The thread keeps the current operation legible while the operator moves between CHAT, CONTROL, MIND, and CAPABILITIES.

## Thread model

- The active operation remains the same while the instrument changes.
- The visible path is `INTENT → ACTION → CONTEXT → ABILITY`.
- The current mission, workspace, model, transition, and runtime state remain attached to that path.
- The hand-off is shown once as a shared thread rather than repeated as duplicate instrument content.
- Previous/current instrument state is retained in session continuity so navigation has causal context.

## Boundaries

The causal thread is presentation and navigation continuity only. It does not create authority, mutate backend state, execute work, or expose private reasoning.

## Principle

**The operator changes instruments; the operation keeps moving.**
