## Cross-milestone invariants

1. Memory does not establish truth.
2. Confidence does not establish certainty.
3. Provenance does not establish authority.
4. Personal-model state does not establish user intent or authorization.
5. Procedural memory does not execute capabilities.
6. Working memory does not become durable memory through the Phase 5 repository.
7. Consolidation proposes; it does not authorize or silently apply.
8. Persistent intelligence does not select providers or cross the existing authority/execution boundaries.

Implementation is complete on the Phase 5 feature branch. Phase verification remains a local user-owned gate and is not implied by this document.
