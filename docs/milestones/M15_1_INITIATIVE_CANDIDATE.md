# M15.1 — Initiative Candidate

## Purpose

Introduce the smallest bounded primitive for proactive agency: an immutable candidate describing a possible opportunity or need that JARVIS may surface.

## Boundary

An initiative candidate is descriptive. It does not authorize action, create policy, prove truth, establish user intent, or request execution.

## Invariants

- Initiative ≠ Instruction
- Initiative ≠ Authorization
- Initiative ≠ Policy
- Initiative ≠ Execution Request
- Prediction ≠ Permission
- Opportunity ≠ Obligation
- Relevance ≠ Mandate

## Integration rule

M15 initiative candidates may later feed proposal and validation paths, but they must enter the existing M7 authority chain before any execution can become authorized.
